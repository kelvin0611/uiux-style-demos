§10

採購同 IT 常見問題

答唔到嘅可以 email 我們，兩個工作日內覆。

10.1可以自架（on-premise）嗎？

可以，企業方案支援；報價按伺服器數量。

10.2資料放喺邊？

香港區伺服器；可以要求書面資料處理協議。

10.3有冇 SOC 2／ISO 認證？

呢個係示範網站，唔代表真實持有；真實情況要在合約前提供證明文件。

10.4點計費？

按用戶數，月付或年付；取消隨時可以，冇綁約期。

10.5可唔可以 API 接我們嘅 ERP？

團隊方案起有 API 同 webhook；我們提供欄位對應文件。

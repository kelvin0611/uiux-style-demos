Quickstart

兩個指令，冇 config 檔都可以跑。

# 1. 安裝（macOS / Linux）
$ brew install brute
# 2. 先睇 plan，唔會改檔案
$ brute refactor --from js --to ts --dry-run
# 3. 套用
$ brute apply --yes

Windows 用 WSL；Docker image 係 `brute:2.4.0`（15 MB），可以喺 CI 直接跑。

FAQ

答唔到嘅開 GitHub issue，我哋每星期覆一次。

會唔會上報任何資料？
唔會。預設零 telemetry，`--version` 之外唔會發任何 request。
支援 Windows 嗎？
WSL 下面跑得；原生 Windows build 係 v2.5 目標。
商用要唔要俾錢？
唔使。MIT 授權，內網同商業環境都可以用。
可唔可以自己加語言支援？
可以。`brute-lang-*` 係 plugin 制，寫個 JSON 對應表就得。
點貢獻？
Fork → 開 branch → 加 test → PR。PR 要有 test 同 changelog 一行。
